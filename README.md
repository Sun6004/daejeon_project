📌 Project Overview
<br>
대전 관광의 문제를 단순히 “볼거리가 부족하다”고 정의하지 않고,
<br>
성심당·야구 등 특정 목적을 달성한 이후 다음 여행 동선을 결정하기 어렵다는 점에 주목했습니다.
<br>
조사 결과를 바탕으로 관광객이 현장에서 이동수단, 소요시간, 주차 등을 다시 검색해야 하는 Planning Fatigue를 핵심 문제로 정의하고, 고민 없이 따라갈 수 있는 취향 기반 대전 여행 코스를 제안했습니다.

📢 02. Distribution & Measurement<br>
<br>
별도의 광고비 없이 실제 사용자 반응을 확인하기 위해 Instagram Reels · YouTube Shorts · Community를 활용해 Organic 배포를 진행했습니다.<br>

각 콘텐츠에서 랜딩페이지로 사용자를 유도하고 GA4를 통해 채널별 유입 데이터를 측정할 수 있는 구조를 구축했습니다.<br>

단순 조회수가 아닌,<br>

콘텐츠 노출 → 시청 → 클릭 → 랜딩페이지 유입<br>

퍼널을 기준으로 성과를 분석했습니다.<br>

📊 03. GA4 Data Analysis<br>
“조회수는 발생하는데 왜 랜딩페이지에는 들어오지 않을까?”<br>

1차 배포 이후 Instagram Reels 데이터를 분석한 결과 다음과 같은 문제를 발견했습니다.<br>

KPI	Result<br>
조회수	1,199회<br>
평균 시청시간	3초<br>
이탈률	79.9%<br>
랜딩페이지 유입	8명<br>
랜딩 유입률	0.67%<br>

조회수 자체는 발생하고 있었지만 조회 → 랜딩페이지 유입 전환이 제대로 발생하지 않는 것이 핵심 병목이었습니다.

🔍 04. Problem Definition

GA4 데이터와 기존 영상을 함께 분석했습니다.

기존 영상은 랜딩페이지를 소개하는 CTA가 영상 후반부에 위치해 있었지만 평균 시청시간은 3초에 불과했습니다.

따라서 많은 사용자가 CTA를 보기 전에 이미 영상을 이탈하고 있을 가능성이 있다고 판단했습니다.

Problem

영상 초반 이탈로 인해 사용자가 랜딩페이지의 가치를 인지하기 전에 콘텐츠를 이탈하면서 랜딩페이지 유입 전환이 저하되고 있다.

🧪 05. Hypothesis & A/B Test
Hypothesis

랜딩페이지를 방문해야 하는 이유와 CTA를 영상 초반에 노출한다면 시청시간과 랜딩페이지 유입률이 증가할 것이다.

분석 결과와 가설을 팀원에게 공유하고, 기존 영상을 그대로 운영하기보다 새로운 숏폼 소재를 제작해 검증할 것을 제안했습니다.

A / B Test

A안 — 기존 영상

랜딩페이지 소개가 영상 후반에 위치
초반 Hooking이 상대적으로 약함
CTA 노출 이전 이탈 가능

B안 — 개선 영상

영상 초반 Hooking 강화
랜딩페이지의 가치를 초반부터 전달
랜딩페이지 소개를 앞·뒤로 반복 노출
CTA 인지 가능성 강화

핵심 테스트 변수는 랜딩페이지 소개 문구의 노출 위치로 설정하고, 조회수보다는 평균 시청시간과 랜딩페이지 유입률을 주요 지표로 확인했습니다.

📈 06. Result

A/B Test 결과 개선 영상에서 주요 퍼널 지표가 개선되었습니다.

KPI	A 기존 영상	B 개선 영상	변화
평균 시청시간	3초	5초	+66.7%
이탈률	79.9%	68.7%	-11.2%p
랜딩 유입	8명	21명	+162.5%
랜딩 유입률	0.7%	1.9%	+171.4%

특히 랜딩페이지 유입률이 0.7% → 1.9%로 약 171% 개선되면서, 단순 조회수를 확보하는 것보다 사용자가 다음 행동으로 이동하도록 콘텐츠 구조를 설계하는 것이 중요하다는 것을 확인했습니다.

💡 07. Growth Insight

이번 프로젝트를 통해 콘텐츠 성과를 조회수 하나로 평가해서는 안 된다는 것을 확인했습니다.

View → Watch → Click → Landing

퍼널을 분리해 확인했기 때문에 “조회수 부족”이 아니라 “시청 이후 랜딩페이지로 넘어가는 전환의 문제”라는 실제 병목을 발견할 수 있었습니다.

또한 첫 3초 Hook, CTA 위치와 반복 노출 등 사용자의 행동에 영향을 주는 변수를 정의하고 실제 테스트를 통해 검증하는 과정을 경험했습니다. 발표자료에서도 후속 액션으로 Hook 문구, CTA 문구·위치, 프로필 링크, 랜딩 첫 화면 CTA 등을 추가 테스트 대상으로 정의했습니다.

🔄 What I Learned

이 프로젝트에서 가장 중요했던 경험은 “데이터를 보는 것”이 아니라 “데이터를 다음 행동으로 연결한 것”이었습니다.

GA4에서 낮은 랜딩페이지 유입률을 발견한 뒤 단순히 결과를 보고하는 데 그치지 않고,

데이터 분석 → 문제 정의 → 원인 가설 → 팀 공유 및 설득 → 신규 소재 제작 → A/B Test → 결과 검증

까지 이어지는 Growth Marketing Cycle을 직접 실행했습니다.

데이터를 통해 문제를 발견하고, 가설을 세우고, 팀을 움직여 실제 실험으로 검증하는 것.
이 프로젝트를 통해 제가 지향하는 그로스 마케터의 업무 방식을 실제 프로젝트에서 경험했습니다.

이렇게 구성하면 특히 이성일 = 랜딩페이지 만든 사람에서 끝나는 게 아니라 제품/접점 구축 → 데이터 수집 → 분석 → 가설 → 팀 설득 → 실험 → 성과를 주도한 사람으로 보이게 돼. 지금 그로스 마케터 취업용이라면 이 차이가 꽤 중요해.
