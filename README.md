## 📌 Project Overview

대전 관광의 문제를 단순히 **'볼거리가 부족하다'**고 정의하지 않고,  
성심당·야구 등 주요 방문 목적을 달성한 이후 **다음 여행 동선을 결정하기 어렵다는 점**에 주목했습니다.

이를 해결하기 위해 취향에 따라 여행 코스를 추천하는 랜딩페이지를 제작하고,  
Instagram Reels와 YouTube Shorts를 통해 실제 사용자 유입을 진행했습니다.

이후 GA4를 활용해 사용자 데이터를 분석하고,

**문제 발견 → 원인 분석 → 가설 수립 → 팀 공유 및 설득 → 신규 숏폼 제작 → A/B Test → 결과 검증**

과정을 수행했습니다.

## 💻 01. Landing Page

### 취향 기반 대전 여행 랜딩페이지 제작

사용자가 여행지를 하나씩 검색하지 않아도 자신의 목적에 맞는 여행 코스를 확인할 수 있도록 랜딩페이지를 제작했습니다.

**주요 기능**

- 취향에 따른 여행 코스 선택
- 추천 코스 및 여행지 확인
- 이동시간 및 이동 루트 제공
- 대전패스 발급
- 카카오톡 친구 공유

특히,

**대전패스 발급 → 친구 공유 → 공유 링크를 통한 신규 랜딩페이지 유입**

구조를 적용해 기존 방문자의 행동이 새로운 사용자 유입으로 연결되는 **Growth Loop**를 설계했습니다.

<br>

## 📊 02. GA4 Data Analysis

### "조회수는 나오는데, 왜 랜딩페이지에는 들어오지 않을까?"

1차 숏폼 배포 후 GA4와 콘텐츠 성과 데이터를 분석했습니다.

| KPI | 1차 결과 |
|---|---:|
| Reels 조회수 | **1,199회** |
| 평균 시청시간 | **3초** |
| 이탈률 | **79.9%** |
| 랜딩페이지 유입 | **8명** |
| 랜딩페이지 유입률 | **0.67%** |

조회수 자체보다 **콘텐츠를 본 사용자가 랜딩페이지까지 이동하지 않는 것**을 핵심 문제로 정의했습니다.

<br>

## 🔍 03. Problem Definition

기존 숏폼의 구조와 데이터를 함께 분석했습니다.

영상의 평균 시청시간은 **3초**에 불과했지만,  
사용자를 랜딩페이지로 유도하는 소개 문구와 CTA는 **영상 후반부에 위치**하고 있었습니다.

따라서 사용자가 랜딩페이지의 가치를 확인하기 전에 영상을 이탈하면서  
랜딩페이지 유입 전환이 낮아지고 있다고 판단했습니다.

### 핵심 문제

> **높은 초반 이탈로 인해 사용자가 CTA를 인지하기 전에 영상을 이탈하면서 랜딩페이지 유입 전환이 저하되고 있다.**

<br>

## 💡 04. Hypothesis

### 가설

> **랜딩페이지를 방문해야 하는 이유와 CTA를 영상 초반에 노출한다면 시청시간과 랜딩페이지 유입률을 높일 수 있을 것이다.**

GA4 분석 결과와 가설을 팀원에게 공유하고,  
기존 영상을 그대로 운영하기보다 **새로운 숏폼을 제작해 가설을 검증하는 A/B Test를 제안했습니다.**

<br>

## 🧪 05. A/B Test

### A안 — 기존 영상

- 랜딩페이지 소개가 영상 후반부에 위치
- 초반 Hooking 상대적으로 약함
- CTA 노출 이전 사용자 이탈 가능

### B안 — 개선 영상

- 영상 초반 Hooking 강화
- 랜딩페이지의 가치를 초반부터 전달
- 랜딩페이지 소개를 앞·뒤로 반복 노출
- CTA 인지 가능성 강화

### 주요 측정 지표

`평균 시청시간` · `이탈률` · `랜딩페이지 유입` · `랜딩페이지 유입률`

<br>

## 📈 06. Result

| KPI | A안 기존 영상 | B안 개선 영상 | 변화 |
|---|---:|---:|---:|
| 평균 시청시간 | 3초 | **5초** | **+66.7%** |
| 이탈률 | 79.9% | **68.7%** | **-11.2%p** |
| 랜딩페이지 유입 | 8명 | **21명** | **+162.5%** |
| 랜딩페이지 유입률 | 0.7% | **1.9%** | **+171.4%** |

### 🎯 Key Result

**랜딩페이지 유입률 0.7% → 1.9%, 약 171% 개선**

단순히 콘텐츠 조회수를 높이는 것이 아니라,  
**사용자가 다음 행동으로 이동하도록 콘텐츠 구조를 개선하는 것이 중요하다는 점을 데이터로 확인했습니다.**

<br>

## 💡 08. Key Insight

이번 프로젝트를 통해 데이터를 단순히 **성과를 확인하는 도구가 아니라 다음 액션을 결정하는 근거**로 활용했습니다.

특히,

**View → Watch → Click → Landing**

퍼널을 나누어 살펴봄으로써 단순한 '조회수 부족'이 아니라  
**시청 이후 랜딩페이지 유입으로 이어지는 전환 구간의 병목**을 발견할 수 있었습니다.

또한 데이터를 분석하는 것에서 끝내지 않고,

**문제 발견 → 가설 수립 → 팀 설득 → 실행 → 실험 → 검증**

까지 연결하며 그로스 마케팅의 문제 해결 프로세스를 직접 경험했습니다.
